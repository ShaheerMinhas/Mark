# Task 1.1 — SearchJob status field

**Branch:** `feat/roadmap-1.1-search-status`  
**Status:** Done (2026-09-12)

## Goal

`SearchJob` tracks lifecycle: `pending` → `running` → `completed` | `failed`, exposed on all search APIs.

## Shipped

- `SearchJobStatus` enum in `backend/models.py`
- Status transitions in `backend/services/search_service.py`
- `GET /searches/{id}` returns empty leads while pending/running; failed returns message
- Export blocked with HTTP 409 until `completed`
- Dashboard shows status; export disabled unless completed

## Test plan

1. Run a saved search → `POST /api/searches` response `search.status` is `completed`
2. `GET /api/searches` lists status per job
3. `GET /api/searches/{id}/export` on a running job → 409 (when worker exists in 1.2)
