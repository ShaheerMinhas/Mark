# Task template

Copy this block when starting a roadmap task (GitHub Issue or personal note).

```markdown
## Task: [ID] Title from ROADMAP.md

**Branch:** `feat/roadmap-X.X-short-name`

### Goal
One sentence — what “done” looks like.

### Scope
- [ ] Backend
- [ ] Frontend
- [ ] Config / deploy
- [ ] Docs

### Checklist
- [ ] Implementation
- [ ] Manual test steps recorded
- [ ] ROADMAP.md checkbox checked
- [ ] Changelog line added

### Test plan
1. …
2. …

### Out of scope (this task)
- …
```

## Branch naming

`feat/roadmap-1.3-search-polling`

## Commit message style

Match existing repo: short imperative, e.g. `Add search job polling API`.
